1. Home `/`: four KPI tiles from scoped research experiment page, reviewed strategy registry,
   completed page count and selected-account risk read; no global profit/safety aggregate. Selected
   immutable result/provenance/equity endpoints drive chart and summary. Real recent rows, actual
   unavailable AI card, scoped safety and six linked research stages. Empty geometry is retained.
2. Strategies `/testeaza/strategii`: registry `/research/strategies`; categories are fixed baseline
   descriptions, never performance/live claims. Counts/search/category filters use the returned
   registry. Inspect exact definition; selecting a strategy returns to the existing reviewed wizard.
3. Backtesting `/testeaza/nou`, `/testeaza`: retain every field, review, idempotency and submission
   handler in StrategyLab; narrow configuration plus wide actual prerequisite/review panel. No
   result/curve before stored data exists. Advanced controls and final holdout stay reachable.
4. Experiments `/testeaza/activitate`: bounded actual experiments, status/search/stage filters,
   summary tiles and compact table. Deep progress/reload, pagination and real acknowledged cancel
   remain. AI requests are not counted as experiments.
5. AI Center `/testeaza/ai`, `/:id`: existing question/context/acknowledgement and inert structured
   answer, with right role/status/limits cards. Suggested text never submits or acknowledges rights.
   Availability uses expiring measured verification and worker status; no model is called online.
6. Results `/rezultate`, `/:id`: one selected stored trial, four server-result tiles, equity/time
   visualization, explicit unavailable distribution unless exact stored counts support it. Existing
   matched-comparison endpoint, replay/statistics/holdout/provenance remain authoritative.
7. Accounts `/conturi`, `/conturi/siguranta`, `/:id/*`: owned list, descriptive simulation context
   clearly separated from actual RiskCenter. Existing three reviewed MFA emergency actions and exact
   policy/profile/context/history remain. Legacy governance CRUD stays visible and reachable.
8. AI Models `/setari/ai`: existing measured registry table, capabilities/expiry, per-role cards and
   secure connection/model/role forms. No browser credential fields, model download or fabricated
   provider connectivity. Existing exact-label browser correction is preserved.
9. Platform `/setari`, `/setari/surse`: source list plus real registration form; settings links to
   market/catalog, observation connectors, manual simulator, users, security, audit and diagnostics.
   Appearance preference remains real. There is no fictional global timezone/quality toggle API.
