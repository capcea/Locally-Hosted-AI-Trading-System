# AI Trading — UI V1 Mockup Handoff

These are **the user's approved concept images**, plus a detailed implementation specification and Codex implementation prompt. **No repository files were changed by ChatGPT.**

## Use on your Mac

1. Download `AI_Trading_UI_V1_Codex_Handoff.zip`.
2. Extract it and copy the folder's contents into your project, for example under `docs/design-reference/ui-v1/`, preserving `references/`, `DESIGN_SPEC.md`, and `CODEX_PROMPT.md`.
3. Open Codex in the project folder and tell it to read `docs/design-reference/ui-v1/CODEX_PROMPT.md`. The visual paths will then be accessible from your own repo.
4. Select **GPT-6 / High** for the full implementation. Medium is suitable for subsequent isolated cosmetic fixes.
5. Before claiming 1:1, manually inspect desktop/mobile captures and test outcomes.

**Important:** image-generator text and figures are demonstrative and sometimes inaccurate. Implement the visual composition faithfully, but use real API data, honest empty states and accurate Romanian copy. Do not treat extracted 512px contact-sheet crops as high-resolution exact measurements.
